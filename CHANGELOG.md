# Changelog

## v1.1.24

- Redesigned the companion app with a two-column tablet layout and a stacked layout for narrower windows.
- Grouped desktop controls and taskbar sizing, with live values alongside each slider.
- Fixed the Classic DeX app grid being clipped to taskbar height. App search opens with the input field focused.
- Restored the native dock when switching back to Workstation and the configured taskbar height when returning to Classic DeX.
- Widened the minimize target and adjusted the handoff between the squeeze animation and Xiaomi’s window transition.
